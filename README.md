# Demo de pago de servicios

Mockup interactivo de una billetera virtual para vincular servicios, consultar facturas de ejemplo y simular pagos.

## Abrir localmente

Abrí `index.html` en un navegador. El mockup usa `localStorage` para conservar los servicios vinculados, el medio de pago elegido y el historial de comprobantes en ese navegador.

## Publicación

El repositorio está preparado para publicar la demo en GitHub Pages mediante GitHub Actions. No integra proveedores reales ni procesa pagos.
